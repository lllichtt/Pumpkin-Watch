# PUMPKIN WATCH

**A short atmospheric horror game about surveillance cameras, mysterious pumpkins, and surviving until 6 AM.**

---

### About the Game

You are a night-shift CCTV operator on Halloween. Strange pumpkins are moving between locations, and your job is to monitor the cameras, track their movements, and stop them before they reach you.

Stay alert, use your spray wisely, and survive until 6 AM. Don't look away for too long…

### Features

- Surveillance system with five camera locations
- Mysterious pumpkins that move between locations
- An atmospheric Halloween horror setting
- A defensive spray mechanic
- A survival challenge: make it until 6 AM

### How to Play

1. Start the game from the main menu.
2. Switch between cameras to monitor the locations.
3. Watch the pumpkins and track their movements.
4. Use the spray when a pumpkin gets to the CAM03.
5. Survive until 6 AM!

### Built With

- Godot Engine
- GDScript
- 2D graphics and shaders

### Installation

**To play:** Download the Windows build from the [Releases](../../releases) page, extract the archive if necessary, and run `PumpkinWatch.exe`.

**To explore the source code:** Clone or download this repository and open `project.godot` in Godot Engine.

### Об игре

Вы — оператор ночного видеонаблюдения в Хэллоуин. Загадочные тыквы перемещаются между локациями, и ваша задача — следить за камерами, отслеживать их передвижения и останавливать их, прежде чем они доберутся до вас.

Будьте начеку, используйте спрей с умом и продержитесь до 6 утра. Только не отворачивайтесь надолго…

2. Переключайтесь между камерами, чтобы следить за локациями.
3. Наблюдайте за тыквами и отслеживайте их перемещения.
4. Используйте спрей, когда тыква добирается до CAM03.
5. Продержитесь до 6 утра!
